# Glacier

Личный трекер инвестиционного портфеля. МосБиржа и криптовалюты, многопользовательский
режим с закрытой регистрацией по инвайт-кодам.

## Стек

| | |
|---|---|
| Фреймворк | Next.js 16, App Router, Server Actions, Turbopack |
| Язык | TypeScript, strict |
| Стили | **Tailwind v4** — конфиг в `src/app/globals.css` через `@theme`. Файла `tailwind.config.js` нет и не нужно |
| Шрифты | Golos Text (интерфейс), IBM Plex Mono (тикеры, коды) — через `next/font` |
| База | **`node:sqlite`**, встроенный в Node. Нативных модулей, ORM и Docker для БД нет |
| Графики | Recharts |
| Тесты | `node --test`, без фреймворка |

Node 22+ обязателен: на нём держится `node:sqlite`.

## Правила, которые легко нарушить по незнанию

**Журнал операций — единственный источник правды.** Позиции, доходность и распределения
всегда выводятся из `transactions`. Никогда не добавляйте денормализованные остатки.

**Деньги — числа в базовой валюте портфеля.** Исторические потоки пересчитываются по курсу,
записанному в самой операции (`fx_rate`), текущие стоимости — по последнему известному курсу.

**Цены облигаций хранятся в деньгах, не в процентах номинала.** MOEX и Алор отдают проценты;
пересчёт делается один раз при сохранении, чтобы арифметика позиций нигде не разбирала класс
актива.

**Любой запрос к данным ограничен `user_id` на уровне SQL.** Идентификатор портфеля из тела
запроса — не основание для доступа. Серверное действие это публичный эндпоинт: скрытая в
интерфейсе кнопка не является авторизацией, каждое действие само вызывает `requireUser`.

**Соединение с БД открывается лениво.** Открытие при импорте модуля ломало сборку: Next
собирает страницы тремя процессами, и они гонялись за один файл SQLite.

**`NODE_EXTRA_CA_CERTS` нельзя задать через `.env`** — переменная читается при старте
процесса, а Next загружает `.env` позже. Запуск идёт через `scripts/with-ca.mjs`.

**Автосинхронизация — отдельный процесс, не часть Next.** `npm run sync:watch` (цикл) или
`POST /api/cron/sync` с `GLACIER_CRON_SECRET` (внешний cron). Оба вызывают `runSyncRound()` из
`src/lib/brokers/scheduler.ts`; флаг `auto_sync` на привязке — единственный переключатель.

## Оформление

Вёрстка — швейцарская типографика, палитра снята с публичного портфеля Snowball Income.
Две темы, тёмная по умолчанию, переключатель в шапке.

- контейнеры — белые/тёмные карточки: рамка `1px`, радиус `8px`, **никаких теней,
  градиентов и размытия**. Глубину держит рамка
- цвет несёт только данные: рост, падение, акцент. Никогда — украшение
- цифра главная: крупная, плотный трекинг, табличные цифры (`.tnum`)
- темы переключаются переопределением переменных `--color-*` в блоке
  `[data-theme="light"]`. Утилиты Tailwind v4 компилируются в `var(--color-*)`, поэтому
  дублировать классы в разметке не нужно
- цвета графиков — тоже `var()`-ссылки: SVG разрешает CSS-переменные в атрибутах заливки

**Категориальная палитра — ровно пять цветов** (`--chart-1…5`), по набору на тему. Это не
вкус, а результат проверки валидатором из скила `dataviz` в режиме `--pairs all` — честном
для кольцевой диаграммы, где все сегменты видны одновременно. Шестая серия сворачивается в
«Другое», а не получает выдуманный оттенок.

Пересчитать палитру: `node scripts/pick-palette.mjs` (валидатор лежит в
`scripts/vendor/`, скопирован из скила, чтобы проверка была воспроизводимой).

## Проверка изменений

```bash
npm test                    # 42 теста расчётного ядра
npx next build              # сборка + проверка типов
node scripts/shots.mjs <токен>   # скриншоты всех страниц + аудит правил оформления
```

`scripts/shots.mjs` проверяет автоматически: тени, градиенты, горизонтальное переполнение,
обрезанные подписи. Токен сессии выдаёт `scripts/make-session.ts`.

Сборку проверяйте **начисто** — `rm -rf .next tsconfig.tsbuildinfo`. Инкрементальная
кэширует ошибки типов, и они всплывают только в CI.

Есть Playwright MCP: можно открыть страницу, кликать, читать DOM и консоль. Для правок
вёрстки пользуйтесь им, а не догадками.

## Чего здесь нет намеренно

- **ORM** — SQL пишется руками в `src/lib/repo.ts`
- **Библиотеки компонентов** — свой набор в `src/components/ui.tsx`
- **Глобального стора** — состояние живёт в URL и серверных компонентах
- **`tailwind.config.js`** — Tailwind v4 настраивается из CSS

## Ограничения, которые не нужно «чинить»

- Публичный API MOEX **не отдаёт дивиденды по акциям** — для них строится прогноз по
  истории начислений, и он всегда помечен как прогноз
- Криптобиржи и Алор отдают **только сделки**, без пополнений и выводов: остаток денег по
  таким портфелям неполный
- Синхронизация с T-Invest **не проверялась на живом токене**
